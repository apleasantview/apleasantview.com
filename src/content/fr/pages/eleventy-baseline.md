## Pour les équipes qui utilisent Baseline

Si votre équipe travaille déjà avec Baseline, ou l'envisage, je peux aider directement.

- **Migrations** depuis WordPress, Hugo, ou d'autres stacks vers un site Baseline.
- **Développement de modules sur mesure** pour les fonctionnalités que le plugin ne couvre pas par défaut.
- **Support de mise en place** pour démarrer un site sur Baseline avec les bons choix d'architecture.
- **Conseil au niveau du mainteneur** sur les internes de Baseline, les requêtes du content graph, ou l'extension du runtime.

Écrivez à [hello@apleasantview.com](mailto:hello@apleasantview.com) et nous discuterons de ce dont vous avez besoin.

<section class="u-flow">

## À propos de Baseline

Si vous arrivez d'ailleurs et vous demandez de quoi il s'agit : Baseline est un plugin pour [Eleventy](https://www.11ty.dev/), un générateur de sites statiques. Il regroupe les éléments dont un site de petite entreprise a généralement besoin (méta-données du head, gestion multilingue, un graphe de contenu interne, un module sitemap) en une seule fondation, pour ne pas avoir à coller douze plugins ensemble.

Ce site est une réalisation Baseline en production. Ce que vous voyez ici, c'est ce que le plugin propose aujourd'hui.

Pour le projet lui-même, y compris la documentation et la référence complète des fonctionnalités : [eleventy-baseline.dev](https://www.eleventy-baseline.dev/).
